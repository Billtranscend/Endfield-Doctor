据点图
          
            

        
图例：每种图怎么看
    
          
  • 放置核对图：左上是每张蓝图的核对结果；红色粗圈 = 疑似少摆的设备最可能的位置，细圈 = 备选位置，橙圈 = 蓝图里没有或多出来的设备。远景标签被挡也会显示成缺，到游戏里看一眼再动手。
    • 
          
  • 底账核对图：红点是基地里扫到的设备，应落在蓝图对应设备上。
    • 
          
  • 暗管连线图：粗线 = 两头都点开确认，细线 = 只确认一头。
    • 
          
  • 物流方向图：橙线 = 传送带、蓝线 = 管道，线上的三角 = 流向（分流器/汇流器的进出口 + 带子管子上的小三角，两者核对过）；灰线 = 方向还定不了。
            物流件旁的红短线 = 分流器进料口，绿短线 = 汇流器出口；紫框 = 上面压着管道、方向按小三角改过。线头绿方块 = 接到的设备（认出了名字），红方块 = 没认出。红圈 = 要人核对（分叉：两条线挨着没法往下追；单向：只从一头追到）。
    • 
          
  • 设计分析图：每台设备一个圈，绿 = 满速、橙 = 间歇、红 = 没料、紫 = 没接上、灰 = 溢流位（平时空闲，主路堵了才用）；旁边是开工率，带 * 的配方是推断的。外面套蓝色虚圈 = 它的来料要经过推断出来的连线；蓝小方块 = 推断连线的两头。
    • 
          
  • 物流件标注图：方框 = 分流器/汇流器/桥（「管」开头的是管道用的）；圆圈 = 准入口，G 后的数字是图标组（同组 = 同一种物品）；蓝圈 = 管道准入口，橙圈 = 物品准入口，灰圈 = 还不知道；外面再套橙色虚圈 = 这格底下可能还叠着物品准入口，到俯瞰里点开看。
    • 
        

        

      

      

        
设计分析（按外部来料算每台设备的设计开工率）
          
            

        
「拼合」时自动算。依据里标〔推断连线〕的那段不是沿带子追出来的（按配方/紧贴/按格子补），配方带「推断配方」的是推断的；这些地方以游戏里实际为准。

        
作者确认：怎么用对着游戏里的实际情况逐台看「开工率 / 状态」：对就点「对」，不对就选实际情况（满速 / 间歇 / 平时空闲（设计如此） / 没在用）并写一句为什么。
          也可以先用上面的筛选挑出一批（比如「没满速的」），核对无误后点「这一页全部确认为对」。确认记录随 zip 导出；别人导入后，只有你确认过的「平时空闲 / 间歇」才会在巡检里当作设计如此、不报问题，没确认的只当参考。

        

        

        

        
推断出来的连线（0 条）

      

      

        
准入口图标分组
          

        
同一组 = 同一种物品。液体、气体图标 → 管道准入口；固体 → 物品准入口。认识的程序已自动填，不认识的请选形态（名字可不填）。

        
「底下可能叠物品准入口」是什么「底下可能叠物品准入口」= 这格有传送带经过，游戏里只显示上面的管道准入口，要到俯瞰里点开那一格看弹出的列表（或按 F2 看传送带图层）。

        

      

      

        
输入端
          

        
红圈 = 程序标的输入端，蓝圈 = 你补的。物品名和液体的量（一口一泵 60/分）已预填，请核对后补上气体的量；单个口流速不同（如 3 号 120/分）直接改那一行。

        
详细说明程序先标出「接入口紧贴基地外侧」的准入口当输入端，水和沉积酸都按一口一泵 60/分预填。贴边但程序判断不是输入的（两旁接着分流器/汇流器、没贴着外侧等）画成灰色虚圈，列在表格下面，判断错了点「加回」；红圈标错了点「删」；漏了的在图上点一下补标。图上按住左键拖动、滚轮缩放，右上「复位」回到整图；单个口的流速不同（如 3 号 120/分）直接改那一行的「每分钟」，巡检和管网都按你填的算。外面先汇流成一个口的勾「汇流口」并填总量。

        
批量填：编号  物品  每口 /分

结构基线（基地改过布局后重设）
            
近景巡检第一次看到每台设备时，会把它周围的管子/带子存成基线，之后拿来比「少了哪段」。基地改过布局、拆装过管子后，旧基线会一直报「少了」：
              趁基地正常时点「重设」，下次巡检按当时的画面重新存。旧基线挪进备份目录，不删。
