# 换一套蓝图时怎么适配

目前只在 1.6 皇帝产线上验证过。整套流程里，**通用的部分不用改**，只有「这套蓝图故意这么设计」的知识要重新采集一次。本文按步骤说明哪些是通用的、哪些要为新蓝图做、以及怎么做。

## 0. 一句话

简报读取、俯瞰巡检、沿配方表往上游追，这三样对任何基地都一样。
换蓝图要做的只有一件事：**把这套蓝图的「备路规则」和「设计限速」写进 `data/tier_rules.json`**，来源是蓝图预览 + 俯瞰里逐个点开的准入口。

## 1. 整条流程和各步的通用性

| 步骤 | 做什么 | 代码 | 通用？ |
|---|---|---|---|
| 简报读取 | F10 打开简报，逐地区滚动读完每种物品的库存、当前/理论产耗，同名灌装瓶靠液滴图标区分 | `src/brief_reader.py` | 通用。物品词表来自 AKEData，游戏版本更新后跑一次 `src/tools/build_data.py` 即可 |
| 配方与上下游 | 哪个设备用什么做什么，每轮几秒 | `data/recipes.json`（AKEData） | 通用 |
| 诊断：爆仓 / 回堵 / 耗库存 | 从产物往上游推 | `src/diagnose.py` | 通用。仓库上限按地区从简报自动取 |
| 诊断：备路与设计限速 | 哪些产物要等主路爆仓才生产；哪些口故意限速 | `data/tier_rules.json` | **蓝图相关，要重新采集** |
| 俯瞰巡检 | 找状态标记、点开设备读名称/状态/配方、扫遍基地 | `src/patrol.py`、`src/badges.py`、`src/panel_recipe.py` | 通用。新出现的设备类型若面板布局不同，要补一次面板适配 |
| 联合结论 | 巡检 + 简报 → 问题 / 待确认 / 正常 | `src/combine.py` | 通用，规则里会查 tier_rules |

## 2. 新蓝图要采集什么

`data/tier_rules.json` 有两段：

```json
{
  "rules": [
    {"product": "低容武陵电池", "requires_full": ["中容武陵电池", "息壤"], "note": "…"}
  ],
  "design_limits": [
    {"product": "中容武陵电池", "note": "景玉谷致密源石粉末准入口限 6，分流后 24/分 → 约 1.2/分"}
  ]
}
```

- **rules（备路规则）**：产物 X 只有在 `requires_full` 里的产物都爆仓后才会满速生产。诊断时 X 产量低、而条件没满足，就判「备路未触发，正常」。
- **design_limits（设计限速）**：蓝图用准入口把某条线故意压低了。诊断时这些产物低于理论值不报问题。

## 3. 怎么从蓝图里把这两段读出来

### 3.1 蓝图预览：先知道有哪些设备和口

F1 → 选蓝图 → 预览。

- 右侧「设备一览」给出每种设备的数量；鼠标悬停任一设备显示名称。**不要靠图标猜**，研磨机/塑形机、赤铜瓶/耐压罐都认错过。
- 预览里能看到管道准入口、物品准入口的位置和它们通过的物品图标，但**看不到限速值**。

### 3.2 俯瞰：逐个点开准入口读限速

CapsLock 进俯瞰，按预览里的位置找到每个准入口，点开读「限制速度」开关和数值。

- 准入口常和传送带、取货口重叠：鼠标按下 → 停约 0.15 秒 → 松开，右侧弹出「管道准入口 / 传送带」选择菜单，再选准入口。快速单击经常不弹菜单。
- 皇帝产线一共 21 个限速口；气体散布机、固气转化机的供气口限 6 是最低需求，不是故障。
- 用户改过的基地（起步口删掉改手动填充、准入口改接暗管、废水接净水节点、清水暗管直供）在功能上和蓝图一样，**以蓝图为准**，不要当成差异。

### 3.3 判断主路 / 备路

设备通常有两条出料：

- **不经汇流器**的那条是主路（一般进仓库或做高级产物）；
- **经汇流器**（1 进 1 出）的那条是备路。只有主路满了（爆仓）物料才会溢到备路。

于是备路产物的 `requires_full` = 主路产物。沿着传送带/管道看哪条经过汇流器，就能列出整张分级表。皇帝产线的分级表：

- 中容爆仓 → 提速锦草软饮 / 芽针针剂
- 中容 + 息壤同时爆仓 → 生产低容
- 息壤爆仓 → 蓝铁瓶液化息壤 → 提速低容
- 高级零件爆仓 → 赤铜零件 → 优质锦草软饮 / 优质芽针针剂

### 3.4 算限速口后面的实际产量

- 传送带 0.5/秒 = 30/分；管道 2/秒 = 120/分。
- 二分分流器后一路被准入口限到 L，另一路得到 S − L。
- 设备产量 = 实际进料 ÷ 满速所需进料 × 满速产量。例：30 − 6 = 24 → 中容需 120/分致密源石粉末 → 24/120 × 6 = 1.2/分。
- 准入口的需求量 = Σ 下游设备（配方每轮用量 × 60 / 每轮秒数 × 开工率），再加上固气/液气转化机、气体散布机各 6/分的最低供给；和限速值、单管 120/分上限比较。

算出来的「设计产量」写进 design_limits 的 note，诊断时用它代替理论值。

## 4. 新设备类型：面板适配

`src/panel_recipe.py` 按配方栏的固定网格认配方：原料格右对齐、产物格左对齐、行居中、需要气体环境的配方上方多一行标签（整排下移 10 像素）。目前验证过：灌装机、配件机、塑形机、精炼炉、天有洪炉。

遇到布局不同的设备（扩容反应池是多配方的「配方一览」、废水处理机没有配方），做法：

1. 用 `src/tools/game_input.py shot 名字` 截一张它的面板；
2. 用 `src/tools/test_recipe.py 名字 设备名 --recipes` 看格子和候选差异；
3. 调整网格参数或为这种面板单写一个读取分支。

状态标记目前只认「阻塞」（红圆环斜杠）和「空闲中」（蓝色 zz）。遇到新标记，从截图里裁出来放进 `resource/badges/`，在 `src/badges.py` 的 `SPECS` 里加颜色条件。

## 5. 换基地 / 换账号时的通用顺序

1. 游戏开到大世界，程序以管理员身份运行。
2. 简报：`src/brief_reader.py --diagnose`，得到每地区的简报和 P2 诊断。
3. 俯瞰：到目标地区，CapsLock 进俯瞰，`src/patrol.py --sweep` 扫遍基地。
4. 合并：`src/combine.py`，看「问题」和「待确认」。
5. 待确认的条目再进俯瞰手动看：准入口限速、传送带断点、管道上限。
6. 看出这套蓝图的备路和限速后，补到 `data/tier_rules.json`，下次诊断就不再误报。

## 6. 以后可以自动化的部分

- 从蓝图预览自动抄设备清单（悬停 + OCR），从俯瞰自动点开准入口读限速，生成结构表（像 `data/皇帝产线-结构.json` 那样），再从结构表推出 tier_rules。这是调研报告里的 P4。
- 跨地区传送（M → 地区总览 → 传送）做成自动，巡检就能一次跑完所有地区。
